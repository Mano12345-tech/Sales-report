# 📊 Sales Performance Dashboard using Power BI

An interactive **Sales Performance Dashboard** built in **Power BI** to analyze sales trends, customer behavior, product performance, and regional sales. The dashboard provides key business insights through interactive visualizations and KPIs, helping users make data-driven decisions.

---

## 📌 Project Overview

This project focuses on analyzing sales data using Power BI. It includes interactive charts, filters, and KPIs that allow users to explore sales performance across different dimensions such as products, customers, regions, and time.

## 🚀 Features

- 📈 Sales trend analysis over time
- 💰 Total Sales, Profit, and Quantity KPIs
- 🌍 Region-wise sales performance
- 🛒 Category and Sub-Category analysis
- 👥 Customer-wise sales insights
- 📅 Time-based filtering (Year, Month, Quarter)
- 🎯 Interactive slicers and filters
- 📊 Easy-to-understand visualizations

## 🛠️ Tools & Technologies
